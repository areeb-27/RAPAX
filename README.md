# RAPAX ✈️

### Real-Time Air Combat Flight Game

RAPAX is a fighter-jet air combat game developed in Unity, focused on fast-paced arcade-style aerial combat.

The project features fighter jet flight controls, targeting, missiles, cannon fire, enemy combat, health systems, and an immersive combat HUD.

---

## 🎮 Features

- ✈️ Arcade-style fighter jet flight system
- 🎯 Target detection and lock-on system
- 🚀 Missile-based combat
- 🔫 Cannon weapon system
- ❤️ Health and damage system
- 🛩️ Enemy aircraft
- 🖥️ Combat HUD
- 🌍 3D combat environment
- 🎮 Keyboard and mouse controls

## 🧠 Core Systems

### Flight Model
The flight system uses an arcade-style approach inspired by modern combat flight games, providing responsive pitch, roll, yaw and throttle controls.

### Targeting System
The targeting system allows the player to detect and select enemy aircraft and maintain a target lock for weapon systems.

### Weapon System
RAPAX includes multiple weapons including:

- Missiles
- Aircraft cannons

### Health System
Aircraft have health and damage handling, allowing combat encounters and destruction states.

### HUD
The combat HUD provides information such as:

- Speed
- Altitude
- Target information
- Target lock status
- Weapon information
- Combat indicators

---

## 🎯 Project Objective

The objective of RAPAX is to develop a playable real-time air combat experience while implementing the core systems required for a fighter-jet combat game.

The project also focuses on understanding game physics, input handling, AI/combat systems, UI development and system integration within Unity.

## 🚀 Getting Started

1. Clone the repository.

4. Open the main scene.
5. Press **Play** to run the game.
